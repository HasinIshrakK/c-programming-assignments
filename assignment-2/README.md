## Short summary of the questions:

1. Is_It_a_Challenge: if input is positive, print 1 2 3 4 5 .... n; else if negative, print n ... -1 0

2. Reverse_and_Odd: Reverse it and only print odd from the given array

3. Say_It: 'I Want More Assignments' should be printed for the given number of times

4. Sum_Sum: Sum of the positive numbers and another for negs

5. Update_and_Print: Replace a certain value from the array with a given number
